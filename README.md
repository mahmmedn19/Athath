# 🛋️ Living Rooms App

A smart Android app that helps users design their ideal **living room** by selecting suitable furniture items based on personal preferences and AI-powered image analysis. Built with **Java**, **Firebase**, and **XML UI**, and integrates with an **API** for image uploading and furniture recognition.

## 👥 System Roles

### 🛠️ Admin Features

- **Vendor Management:**
  - View vendor profile
  - Accept / Reject vendor
  - Block vendor

- **Customer Management:**
  - View customer info
  - Block customer

- **Room Suggestion Settings:**
  - Color preferences (light, dark, neutral)
  - Plants existence (yes/no)
  - TV existence (yes/no)
  - Flooring type: Parquet, Ceramic, Carpet
  - Room type (Living, Reception, etc.)
  - Design style (Modern, Classic, etc.)

---

### 🛍️ Vendor Features

- Sign Up / Login / Password Reset / Logout  
- Manage personal profile  
- Manage store information  
- Manage furniture products:
  - Add product
  - Edit product
  - Delete product

---

### 👤 Customer Features

- Manage personal profile  
- Answer room preference questions  
- View AI-generated room suggestions  
- View furniture components of each suggestion (based on AI & database)  
- Select desired furniture:
  - Add to favorites
  - View product details
- Manage favourites:
  - View list
  - Remove product
  - View product details

---

## 🔧 Technologies Used

- **Java (Android)**
- **XML UI Layouts**
- **Firebase:**
  - Firebase Authentication
  - Firestore Database
  - Firebase Storage
- **REST API:**
  - Upload image
  - AI-powered image analysis (furniture detection and suggestion)
